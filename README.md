## Juego en el tren

### I'm Using no build

#### For building the firt time run:

```
cc buildgame.c -o buildgame && ./buildgame
```


#### Once `buildgame` was build you can rebuild with

```
./buildgame
```


#### If you want to run it, simply run:


```
./buildgame -run
```


#### deps

You will need to download / clone the deps under `/deps` folder... for now is only raylib, the link is present in the folder readme.
